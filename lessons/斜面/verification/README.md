# 《斜面》课堂流程核查

`current/` 是从离线成品 `output/斜面_胡拉拉课堂版.html` 在真实 Chrome 浏览器中截取的本轮课堂流程图片。录入的数值仅存在于独立测试浏览器会话；课堂成品没有预设实验数据。

- `01`：搬货难题动画进行中，斜面尚未展示。
- `02`、`02b`、`03`、`04`：无数据、六组录入、部分数据和完整数据小窗。
- `05`、`05b`：中央图表大屏的观察状态与教师揭示状态。
- `06`、`07`：山路问题动画结束与客户新家、无预设道路的山体。
- `07a`：教师显示设计提示；`07b`、`07c`、`07d`：房屋正面、侧面、背面观察。
- `08`、`08b`：鼠标绘制完成与旋转后的贴地路线；`09`、`10`：1440×900、1920×1080 山地视图及触摸绘制完成。
- `11`～`14`：货车回到山脚、暂停转山、跨视角续画四段绕山路线及完成后的整体观察；`15`：触摸跨视角续画。

`classroom-flow-check.cjs` 检查两段问题动画、货车行进方向与小幅坡度俯仰、设计提示显示隐藏、六组数据、各项独立平均、排除某组后的数据点、图表放大与延迟揭示、鼠标和触摸绘制、清除重画、旋转后路线显示、相机旋转缩放恢复、三种目标分辨率、全屏、刷新恢复及 JavaScript 控制台。图表与路线图片中的数值、线条由测试操作产生，不在课堂成品中预设。

`route-multiview-check.cjs` 另行检查绘制前货车返回山脚、远离终点时拒绝强连、四段绕山路线跨视角保留、清除，以及触摸单指绘制、单指旋转、双指缩放和续画。路线从学生方案操作生成；截图中的路线不会预置到课堂成品。

用户已确认右下角机器人是 Codex 桌面宠物，不属于课程 HTML。课件不调整该宠物，右侧研讨按钮保持原有宽度。
