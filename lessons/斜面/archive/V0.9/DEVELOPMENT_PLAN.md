# 《斜面》最终开发方案

## 教学定位

本课沿用“胡拉拉搬家公司”任务：先解决同一件重物上货车的问题，再把斜面认识迁移到货车上山的路线设计。学生先预测、观察和表达，再由教师揭示讨论提示。

真实实验承担测量与测试。3D 场景只帮助全班看清结构、比较路线，不生成实验拉力、坡度或省力百分比，也不呈现为真实过程录像。

## 项目一：货物搬上车

- 实验对象：同一件货物或重物。遥控货车不作为弹簧测力计测量对象。
- 比较条件：同一重物、同一目标高度、同一种测量方式。比较直接提起、短斜面、中斜面、长斜面的拉力。
- 实物活动：学生用弹簧测力计沿搬运方向缓慢、尽量匀速地拉；按工作日志重复测量、记录并计算平均值。
- 平台情境：程序化 3D 货车、货物、货车平台和三块同高度斜面；可选择结构、观看搬运路径示意、旋转或复位视角。
- 数据研讨：教师录入各组**真实测得的平均拉力**，单位 N。平台按组切换，图形只依据录入值绘制，并突出当前选中的搬运方式。数据不足时保持空白；数据不符合预期时提示核查实验条件，不修改实测结果。

## 项目二：货车上山

- 学生继续使用木板、高台和遥控货车设计、调试并测试路线，汇报实物作品。
- 平台提供真实 3D 山地场景，逐步展示直上、曲折、盘绕三种路线结构，并可叠加比较。山体为程序化简化几何示意。现有 Mountainside 素材经试放会遮挡路线，因此本课未采用，也未新增素材。
- 全班讨论可否通行、转弯与路宽、结构稳固等问题；不得宣称盘山路线一定更安全。

## 课堂流程与界面

情境呈现 → 问题提出 → 真实实验 → 真实数据汇总 → 3D 结构比较 → 学生归纳 → 实物工程设计 → 3D 山地迁移。

页面分为“情境与预测”“真实数据研讨”“上山路线迁移”三步。中央是 3D 舞台，左侧选择结构或路线，右侧显示当前问题、实测数据和教师控制的研讨提示。优先适配 1366×768、1440×900、1920×1080；支持鼠标、触摸屏与全屏展示。

## 科学与技术边界

- 在同一目标高度等可比条件下讨论斜面长度、坡度与拉力；真实摩擦、操作差异可能使个别实测数据偏离预期。
- 不把“功”作为本课学生的核心概念；不将更长的路程等同于更大的功。
- 3D 路线是简化结构模型，不给出虚构的精确坡度、力或安全结论。
- 成品为单文件离线 HTML，已内嵌本地固定版本 Three.js；运行时不访问 CDN、在线字体、图片、模型或 API。

## 文件与构建

- 课堂成品：`output/斜面_胡拉拉课堂版.html`，直接双击打开。
- 可维护源码：`src/index.html`、`src/styles.css`、`src/main.js`。
- 重新构建：在本课程目录运行 `npm install` 后运行 `npm run build`。
- Three.js 许可证文本内嵌于成品。
