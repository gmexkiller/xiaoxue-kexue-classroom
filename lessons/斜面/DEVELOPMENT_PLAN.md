# 《斜面》课堂版开发说明

## 教学定位

本课沿用“胡拉拉搬家公司”任务：先解决同一件重物上货车的问题，再把斜面认识迁移到货车上山的路线设计。学生先预测、观察和表达，再由教师揭示讨论提示。

真实实验承担测量与测试。3D 场景只帮助全班看清结构、比较路线，不生成实验拉力、坡度或省力百分比，也不呈现为真实过程录像。

## 项目一：货物搬上车

- 实验对象：同一件货物或重物。遥控货车不作为弹簧测力计测量对象。
- 比较条件：同一重物、同一目标高度、同一种测量方式。比较直接提起、短斜面、中斜面、长斜面的拉力。
- 实物活动：学生用弹簧测力计沿搬运方向缓慢、尽量匀速地拉；按工作日志重复测量、记录并计算平均值。
- 平台情境：程序化 3D 货车、货物、货车平台和三块同高度斜面。3.8 秒问题动画仅让货物短距离抬起、减速停顿并放回；学生提出办法后才由教师展示斜面结构。
- 数据研讨：各组对四种方法分别测量三次，在纸质工作日志中计算本组平均拉力。教师录入六组真实平均值，单位 N。六组使用一致的重物、提升高度、斜面规格和材料、测量方法与操作规范。条件明显不同的小组可取消参与全班平均，记录仍保留为数据点。
- 每项全班平均独立计算，空白不参与分母，真实录入的 0 参与计算。图表以从 0 开始的纵轴展示四项全班平均柱和各组数据点；右侧为缩略图，可放大到中央舞台。学生表达后教师才揭示结论。

## 项目二：货车上山

- 学生继续使用木板、高台和遥控货车设计、调试并测试路线，汇报实物作品。
- 山顶地形以同一高度函数形成椭圆形小平台，中心平缓、边缘平滑接回山体；房屋保持垂直，以薄石质地基轻微嵌入平台，并留小块到达区域，不预铺道路。
- 4.8 秒山路问题动画先展示山脚货车与山顶客户新家，再让货车尝试直接上坡、逐渐减速并停住约 0.9 秒。车头由路径切线决定水平朝向，车身根据沿路高差小幅俯仰。
- 学生实物设计、测试、调整并汇报后，教师进入固定视角绘制，将屏幕轨迹投射到 3D 地形，形成贴地的学生方案示意线。完成时仅轻度修正小锯齿，保留学生路线走向和转弯。绘制状态锁定相机，完成后恢复旋转缩放。可清除和重画。
- 主山体仍为连续高度网格；现有 Mountainside 模型用作侧后方岩层，配合已登记的本地土壤与岩石纹理。没有预设的直上、曲折、盘绕选项及道路。
- 项目二设计提示由教师点击显示或隐藏，在学生提出和测试方案前不出现。全班可讨论能否通行、转弯与路宽、结构稳固等问题；不得宣称盘山路线一定更安全。

## 课堂流程与界面

问题动画 → 学生提出办法 → 真实实验 → 真实数据汇总 → 学生归纳 → 实物工程设计与测试 → 3D 山地展示学生方案。

页面分为“搬货难题”“数据找规律”“山路挑战”三步。保留左侧控制、中央 3D、右侧研讨的三栏结构。图表大屏模式临时占用中央舞台。优先适配 1366×768、1440×900、1920×1080；支持鼠标、触摸屏与全屏展示。

山路阶段保留简洁的“生活中的斜面”观察提示。结论限定在本组本次记录和全班已录入的可比数据范围内，由学生先归纳，再由教师揭示。

视觉精修中，项目一场内只显示当前选中的搬运方式标签，保留“同一件货物”和“同一货车平台高度”的教学标识。真实数据页面在尚无实测记录时显示课堂空状态，教师录入后才绘制图表。

## 科学与技术边界

- 在同一目标高度等可比条件下讨论斜面长度、坡度与拉力；真实摩擦、操作差异可能使个别实测数据偏离预期。
- 不把“功”作为本课学生的核心概念；不将更长的路程等同于更大的功。
- 3D 路线是简化结构模型，不给出虚构的精确坡度、力或安全结论。
- 成品为单文件离线 HTML，已内嵌本地固定版本 Three.js；运行时不访问 CDN、在线字体、图片、模型或 API。
- 当前标签页用 `sessionStorage` 临时保存教师提交的小组名称和真实数据；刷新后恢复，关闭标签页后不作为长期存档。
- 本轮保持课堂版待教师实看，不冻结为 V1。

- 可维护源码：`src/index.html`、`src/styles.css`、`src/main.js`。

- Three.js 许可证文本内嵌于成品。
